# Simple Portfolio Website

A responsive portfolio built with plain HTML, CSS, and JavaScript. No frameworks, dependencies, or build commands are required.

## Customize it
1. Open `index.html`.
2. Replace `Your Name` and `YN` with your name/initials.
3. Update the intro, skills, and project descriptions.
4. Replace the example GitHub, LinkedIn, and email links with your own.

## Run locally
Open `index.html` in your browser.

## Push to GitHub
Create a new empty repository on GitHub, then run these commands inside this folder:

```bash
git init
git add .
git commit -m "Add portfolio website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

## Deploy on Vercel for free
1. Sign in at https://vercel.com/ using GitHub.
2. Click **Add New → Project**.
3. Import your portfolio repository.
4. Leave Framework Preset as **Other** (or static site), and leave build/output settings empty.
5. Click **Deploy**.

Every future push to the connected GitHub repository will trigger a new deployment.
